# Held-back operators

Operators of the features held back from the first release (PyEyesWeb `@describe(..., released=False)`). They are not
built: CMake globs only the layer folders under `chops/`. A feature that returns moves its file back to its layer
folder, updated to the API of its feature. The four humanoid and generic-model operators predate the merge into
`MassSpringSimulator`, which will replace them with one operator.
